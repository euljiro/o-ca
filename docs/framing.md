# 오늘의 기운 운세 카드 — 프레이밍

합의일: 2026-11-22

| 항목 | 내용 |
|---|---|
| 배경 | 바이브 디자인 연습으로 만든 운세 카드 프로토타입을 실제 사용자가 쓰는 제품으로 출시해 본다. |
| 목적 | 글자뿐인 운세를, 매일 열어보고 싶은 수집형 그래픽 카드로 바꾼다. |
| 성공 기준 | 토스 앱(앱인토스)에 출시하고, 카드 공유로 새 사용자가 들어온다. 공유 수와 공유를 통한 유입으로 판단한다. 목표 수치는 `미정`. |
| 방향 | 생년월일을 입력하고, 태어난 시는 입력하되 모르면 건너뛴다. 오늘과 어제 운세 카드를 본다. 친구에게 카드 형태로 공유한다. 운세 문장은 가능한 경우의 수를 모두 따져 미리 최대한 많이 만들어 두고, 사람마다 겹치지 않게 하는 것을 목표로 한다. 디자인은 현재 프로토타입(`prototypes/fortune-card.html`)을 바탕으로 한다. |
| 하지 않을 것 | 내일 운세, 날짜를 골라 보는 운세. |
| 대상 사용자 | 토스 앱 사용자, 공유받은 카드로 들어오는 친구. |
| 제약 | 무료로 운영한다(서버·외부 API 비용 없음). 기획·디자인·개발을 혼자(+AI) 한다. |

## 미정·확인 필요

- 유료·광고, 친구와의 궁합·비교 기능을 할지 `미정`
- 태어난 시를 입력하면 운세가 무엇이 달라지는지 `미정` (현재 프로토타입은 태어난 날만 계산에 사용)
- 앱인토스 출시 요건 `확인 필요`: 사업자 등록 필요 여부, 운세 콘텐츠 심사 기준, 공유 기능 지원 방식
- 공유받은 친구가 토스 밖에서도 카드를 볼 수 있어야 하는지 `미정`. 토스 밖에서 보이게 하려면 웹 호스팅이 필요하고, 무료 운영 제약과 맞는지 `확인 필요`
- 점수(총운·금전·애정·일·학업·건강) 계산 기준 `미정` (현재는 임시 값)
- 기존 소원 프로젝트(sowon)를 중단할지, 함께 갈지 `미정`
