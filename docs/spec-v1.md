# 오늘의 기운 v1 — 상세 기획서 (초안)

작성 2026-11-22 · 기준: `framing.md`, `appsintoss-research.md`, `privacy-research.md`

## 작업 범위

- **포함**: 시작(정보 입력) 화면, 운세 카드 화면(오늘·어제), 내 정보 수정·지우기, 공유 링크 보내기, 공유받은 화면
- **2차 범위**: 내일·날짜 지정 운세, 카드 이미지 저장, 친구 궁합, 광고, 태어난 시를 운세 내용에 반영하는 방식(`결정 필요`)

## 1. 개요

### 배경
운세 카드 프로토타입을 앱인토스 미니앱으로 출시하기 위해, 처음 쓰는 사람의 흐름과 공유 흐름을 화면 단위로 정한다.

### 목표
- 처음 온 사람이 생년월일만 넣고 바로 오늘 카드를 본다.
- 오늘·어제 카드를 넘겨 보고, 친구에게 공유 링크로 보낸다.
- 링크를 받은 친구가 보낸 사람의 카드를 보고 자기 운세로 넘어온다.

### 용어
- **카드**: 하루치 운세 한 장. 위쪽 그래픽(오행 그라데이션·라인 장식·3D 아이콘)과 아래쪽 운세 정보로 이루어진다.
- **내 정보**: 생년월일과 태어난 시(선택). 이 기기에만 저장된다.
- **일간**: 생년월일로 정해지는 나의 오행 기운(10가지 중 하나). 카드에 `나 乙木`처럼 표시된다.

## 2. 적용 범위

- **화면**: 토스 앱 안 미니앱 전체 (토스 내비게이션 바 아래 영역)
- **이용자**: 토스 앱 사용자 (앱인토스 정책상 만 19세 이상)
- **진입 경로**
  - 토스 앱에서 미니앱 직접 실행 → 내 정보 없음: 시작 화면 / 있음: 운세 카드 화면(오늘)
  - 공유 링크로 실행 → 공유받은 화면
- **페이지 공통 상태**
  - 로딩: 카드 자리에 그래픽 없는 빈 카드 틀(회색)을 먼저 보여주고, 그래픽이 준비되면 채운다
  - 그래픽을 그릴 수 없는 기기: 오행별 정지 이미지로 대체 (`확인 필요`: 대체 이미지 준비 방식)
  - 오류: "카드를 불러오지 못했어요" + [다시 시도] (문구 초안)
- **화면 모드**: 라이트 모드만 (앱인토스 정책)

## 3. 정보 구조

| 화면 | 역할 | 유형 |
|---|---|---|
| 시작 화면 | 내 정보 첫 입력 | 신규 |
| 운세 카드 화면 | 오늘·어제 카드 보기, 공유 | 기존 프로토타입 개선 |
| 내 정보 시트 | 내 정보 수정·지우기 | 기존 시트 개선 |
| 공유 | 공유 링크 보내기 | 신규 |
| 공유받은 화면 | 보낸 사람 카드 보기 → 내 운세로 이동 | 신규 |

## 4. 화면별 상세

### 4-1. 시작 화면 (신규)

첫 진입 시 바텀시트가 아니라 **전체 화면**으로 보여준다 (앱인토스 정책: 진입 직후 바텀시트 금지).

**구성 (위에서 아래로)**
- 제목: "오늘의 기운을 알려드릴게요" (문구 초안)
- 설명: "태어난 날로 나의 오행을 계산해요" (문구 초안)
- 생년월일 입력
- 태어난 시 선택
- 안내 문구
- [오늘의 기운 보기] 버튼 (화면 하단 고정)

**생년월일**
- 필수
- 입력 방식: 날짜 선택
- placeholder: "1995. 03. 15" (문구 초안)
- 입력 제한: 1920-01-01 ~ 오늘. 미래 날짜는 고를 수 없다
- 기본값: 없음 (빈 값)
- 입력하면 아래에 바로 표시: "나의 일간은 을목(乙木) · 풀꽃" (계산 결과)

**태어난 시**
- 선택
- 입력 방식: 12개 시간대 중 하나 + [모름]

  | 시간대 | 표시 |
  |---|---|
  | 23:30~01:29 | 자시 |
  | 01:30~03:29 | 축시 |
  | 03:30~05:29 | 인시 |
  | 05:30~07:29 | 묘시 |
  | 07:30~09:29 | 진시 |
  | 09:30~11:29 | 사시 |
  | 11:30~13:29 | 오시 |
  | 13:30~15:29 | 미시 |
  | 15:30~17:29 | 신시 |
  | 17:30~19:29 | 유시 |
  | 19:30~21:29 | 술시 |
  | 21:30~23:29 | 해시 |

  시간대 경계(30분 기준)는 `확인 필요` (만세력 기준과 대조)
- 기본값: 선택 안 함
- [모름]을 누르면 시간대 선택이 해제되고 [모름]이 선택 상태가 된다
- 툴팁: "태어난 시를 알면 더 자세한 운세를 볼 수 있어요" (문구 초안) — v1에서는 시를 운세 내용에 반영하지 않으므로 문구 `결정 필요`

**안내 문구**
> 입력한 정보는 이 기기에만 저장돼요. 서버로 보내지 않고, 만든 사람도 볼 수 없어요. (문구 초안)

**[오늘의 기운 보기] 버튼**
| 상태 | 조건 | 동작 |
|---|---|---|
| 비활성 | 생년월일이 비어 있음 | 눌리지 않음 |
| 활성 | 생년월일이 입력됨 (태어난 시는 상관없음) | 내 정보 저장 → 운세 카드 화면(오늘)으로 이동 |

- 하지 않는 것: 이용약관·개인정보 동의 단계를 따로 두지 않는다 (`privacy-research.md` 기준, 채널톡 답변에 따라 변경 가능)
- 뒤로가기: 첫 화면이므로 미니앱이 종료된다 (앱인토스 정책)

### 4-2. 운세 카드 화면 (개선)

> **v1.1 레이아웃 변경 (2026-11-22)**: 스토리형으로 전환. 카드가 화면 전체를 쓰고(상하좌우 16px 여백) 그래픽이 카드 전체에 깔린다. 위쪽에 진행 막대 2칸(어제·오늘), 가운데에 아이콘과 **키워드**(관계 이름에서 "의 날"을 뺀 단어, 예: 단련), 한마디, 타일 3개(총운·힘이 되는 것·조심할 것), 아래에 [친구에게 보내기]. 좌우로 밀거나 왼쪽·오른쪽 3분의 1을 눌러 넘긴다. 점수는 총운만 보이고 금전·애정·일·학업·건강은 이번 레이아웃에서 뺐다(`결정 필요`: 다시 넣을지). 공유받은 화면도 같은 스토리형 카드 1장. 아래 넘김 표시(점)·가장자리 미리보기 설명은 진행 막대로 대체됨.

**구성 (위에서 아래로)**
- 상단 줄: 날짜("11.22 SUN") · [내 정보] 버튼
- 카드 (좌우로 넘김)
- 넘김 표시: 점 2개 (어제 · 오늘), 현재 카드 점 강조
- [친구에게 보내기] 버튼 (화면 하단 고정)

**카드 넘기기**
- 기본으로 **오늘** 카드를 보여준다
- 오늘 카드에서 오른쪽으로 밀면 어제 카드, 어제 카드에서 왼쪽으로 밀면 오늘 카드
- 카드는 2장뿐이다. 오늘 카드에서 왼쪽으로 밀거나 어제 카드에서 오른쪽으로 밀면 살짝 밀렸다가 제자리로 돌아온다
- 넘김을 알아차릴 수 있게 오늘 카드 왼쪽 끝에 어제 카드 가장자리를 살짝 보여준다 (`결정 필요`: 보이는 폭)
- 상단 날짜는 현재 보고 있는 카드의 날짜로 바뀐다. 어제 카드에는 날짜 옆에 "어제" 표시
- 점(넘김 표시)을 눌러도 해당 카드로 이동한다
- 하지 않는 것: 어제보다 이전, 내일 이후 카드는 만들지 않는다

**카드 내용** (프로토타입 유지, 디자인 리뷰 반영)
- 그래픽: 비율 고정(`결정 필요`: 4:5 제안). 남는 세로 공간은 여백으로 둔다
- 관계 표시: "단련의 날 / 관성" — 관계 이름 옆 용어(관성 등)에 설명을 붙일지 `결정 필요`
- 오늘의 한마디 (제목)
- 점수 5개: 총운·금전·애정·일·학업·건강. 한 줄 가로 띠(항목명·숫자·짧은 막대)로 표시 — 그래픽 4:5 비율을 지키면서 한 화면에 들어가도록 (프로토타입 v1 기준, 변경 가능)
- 길한 것, 조심할 것

**[내 정보] 버튼**
- 누르면 내 정보 시트가 열린다
- 표시: "내 정보" (현재 `나 乙木` 한자 표시를 글자로 변경)

**[친구에게 보내기] 버튼**
- 누르면 현재 보고 있는 카드(오늘 또는 어제)의 공유가 시작된다 → 4-4

**자정이 지나면**
- 화면을 연 채로 날짜가 바뀌면, 다음에 화면으로 돌아올 때 새 오늘 카드로 갱신한다 (`결정 필요`: 즉시 갱신 여부)

### 4-3. 내 정보 시트 (개선)

**열기**: [내 정보] 버튼을 눌렀을 때만 연다 (자동으로 열지 않는다)

**구성**
- 제목: "내 정보" (문구 초안)
- 생년월일 (4-1과 같음, 저장된 값이 채워진 상태)
- 태어난 시 (4-1과 같음)
- 안내 문구 (4-1과 같음)
- [저장] 버튼
- [내 정보 지우기] 텍스트 버튼

**[저장]**
| 상태 | 조건 | 동작 |
|---|---|---|
| 비활성 | 바뀐 값이 없음 | 눌리지 않음 |
| 활성 | 생년월일 또는 태어난 시가 바뀜 | 저장 → 시트 닫힘 → 카드 갱신 → toast "내 정보를 바꿨어요" (문구 초안) |

**[내 정보 지우기]**
- 확인 모달
  - 제목: "내 정보를 지울까요?"
  - 내용: "이 기기에 저장된 생년월일과 태어난 시가 지워져요."
  - 버튼: [취소] / [지우기] (문구 초안)
- [지우기] → 저장된 정보 삭제 → 시작 화면으로 이동

**닫기**
- 시트 바깥 영역을 누르거나 아래로 내리면 닫힌다
- 바뀐 값이 있는데 닫으면: 저장하지 않고 닫는다 (`결정 필요`: 확인 모달을 띄울지)

### 4-4. 공유 (신규)

- [친구에게 보내기] → 토스 공유 화면이 열린다
- 함께 보내는 문구: "오늘 내 기운은 '피드백은 선물로 받기'래요. 당신의 오늘도 확인해 보세요" (문구 초안 — 카드의 한마디가 들어감)
- 링크 미리보기 이미지: 모든 카드에 같은 고정 이미지 1장 (1200×600) (`확인 필요`: 앱 안 이미지를 미리보기로 쓸 수 있는지)
- 링크에 담기는 정보: **카드 번호** — 카드 날짜, 보낸 사람의 일간(10가지 중 하나), 뽑힌 한마디·조심할 것·점수. 받은 사람은 이 번호로 같은 카드를 다시 그린다
- 하지 않는 것: 생년월일·태어난 시를 링크에 담지 않는다
- 공유 링크는 정식 출시 후에만 동작한다 (앱인토스 제약). 출시 전 테스트 방법 `확인 필요`

### 4-5. 공유받은 화면 (신규)

**구성**
- 상단 안내: "친구의 11월 22일 기운이에요" (문구 초안)
- 보낸 사람의 카드 (넘기기 없음, 1장)
- [내 오늘 운세 보기] 버튼 (화면 하단 고정)

**카드 내용**
- 보낸 사람이 본 카드와 같은 내용(그래픽·한마디·점수·길한 것·조심할 것)을 보여준다
- 날짜는 보낸 사람이 공유한 카드의 날짜다. 다음 날 열어도 그 날짜 카드를 보여준다

**[내 오늘 운세 보기]**
| 받은 사람 상태 | 이동 |
|---|---|
| 내 정보 있음 | 운세 카드 화면(오늘) |
| 내 정보 없음 | 시작 화면 |

**예외**
- 링크 정보가 잘못됐거나 읽을 수 없음: 공유받은 화면 대신 진입 경로 기본 규칙(시작 화면 또는 운세 카드 화면)으로 보낸다
- 토스 앱이 없는 사람: 앱스토어/플레이스토어로 이동한다 (앱인토스 동작, 별도 처리 없음)

## 5. 구현 고려 (개발 참고)

- **카드 번호 방식으로 결정 (2026-11-22)**: 내 카드는 생년월일 전체와 날짜로 골라 사람마다 다르게 하고, 공유 링크에는 뽑힌 결과(카드 번호)만 담는다. 개인정보 없이 받은 사람도 같은 카드를 본다
- 내 정보는 앱인토스 기기 저장소에 저장한다. 토스 앱을 지우면 함께 지워진다
- 글꼴·3D 라이브러리를 외부에서 불러오지 않고 앱 안에 넣는다 (`확인 필요`: 외부 리소스 제한)
- 점수는 아직 임시 계산이다 (`결정 필요`)
