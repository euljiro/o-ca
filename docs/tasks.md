## 1. 운세 규칙 확정

- [ ] 태어난 시를 입력하면 달라지는 것 결정 (시주 반영 범위)
- [ ] 계산 정확도 검증: 일진·일간 계산을 만세력과 대조
- [ ] 점수(총운·금전·애정·일·학업·건강) 계산 기준 결정
- [ ] 문장 조합 구조 설계: 경우의 수(나의 일간 × 오늘 일진 × 시 등)와 문장 슬롯(한마디·길한 것·조심할 것)
- [ ] 문장 대량 생성 및 검수 (중복·어색한 표현·심사 기준 위반 표현)

## 2. 상세 기획

- [ ] 사용자 흐름: 첫 진입 → 생년월일·시 입력 → 오늘 카드 → 어제 카드 → 공유
- [ ] 화면별 상세 기획: 입력 화면, 카드 화면, 공유 시트, 공유받은 사람이 보는 화면
- [ ] 상태별 처리: 시 모름, 입력 수정, 로딩, 그래픽(WebGL) 미지원 기기, 오류
