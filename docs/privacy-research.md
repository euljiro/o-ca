# 생년월일 개인정보 처리 조사

조사일: 2026-11-22 · 법률 자문 아님. 확정이 필요한 항목은 앱인토스 채널톡이나 전문가 확인 필요.

전제: 생년월일·태어난 시는 앱인토스 `Storage`(기기 저장)에만 둔다. 서버 전송 없음, 토스 로그인 없음. 공유 링크에 생년월일을 넣지 않는다.

## 결론

이 구조라면 처리방침을 법적으로 꼭 만들어야 한다는 근거는 약하다. 다만 개인정보위 지침(2026-04 개정)이 "기기 안에서만 처리되면 그 사실과 삭제 기준을 안내하라"고 **권장**하므로, 입력 화면 안내 문구와 간단한 처리방침 페이지를 준비한다.

## 앱인토스 정책

| 확인된 것 | 출처 |
|---|---|
| 앱 등록 항목에 처리방침 URL이 없다 (로고, 이름, 고객문의 이메일, 카테고리, 설명, 키워드 등) | [FAQ](https://developers-apps-in-toss.toss.im/guide/faq.md), [미니앱 등록](https://developers-apps-in-toss.toss.im/guide/operation/console-workspace.md) |
| 약관·동의 등록은 토스 로그인을 쓸 때의 절차다. 토스 로그인은 사업자등록 필요 | [토스 로그인](https://developers-apps-in-toss.toss.im/guide/authentication/intro.md) |
| 익명 사용자 키는 동의 없이 쓸 수 있다 | [사용자 식별키](https://developers-apps-in-toss.toss.im/guide/authentication/anon-key.md) |
| 이벤트 로그에 개인정보를 넣으면 안 된다 | [로그 가이드](https://developers-apps-in-toss.toss.im/guide/analytics/logging.md) |
| 콘솔의 성별·연령은 토스가 주는 집계 통계다 | [대시보드](https://developers-apps-in-toss.toss.im/guide/analytics/dashboard.md) |
| 법률상 고지 목적의 외부 링크는 허용될 수 있다 | [서비스 오픈 정책](https://developers-apps-in-toss.toss.im/guide/undefined.md) |
| 토스에 저장된 생년월일을 불러오는 기능은 제3자 제공 동의 화면이 뜬다 → 직접 입력 방식이면 무관 | [사용자 정보](https://developers-apps-in-toss.toss.im/guide/authentication/user-info.md) |

`확인 필요`: 로그인 없는 앱에 검수자가 처리방침을 요구하는지 (문서·후기 어디에도 없음)

## 법·지침

- 개인정보위 「개인정보 처리방침 작성지침」 2026-04-24 개정 (언론·기업 해설로 확인, 원문 미확인 `확인 필요`)
  - 서버에 일부라도 저장되면 처리방침 작성 필요
  - 단말기 안에서만 처리되면 그 사실과 삭제 기준 안내를 **권장**
  - 출처: [뉴시스](https://mobile.newsis.com/view/NISX20260424_0003604909), [바이라인](https://byline.network/2026/04/24-580/), [카카오 프라이버시](https://brunch.co.kr/@kakaoprivacy/92)
- 생년월일 단독이 개인정보인지 판단한 공식 자료는 못 찾음. 민감정보 목록에는 없는 것으로 보임 (조문 원문 `확인 필요`)
- 운영자가 데이터에 접근할 수 없는 구조면 개인정보처리자 해당 여부부터 다툴 여지가 있음 (공식 해석 아님)

## 다른 운세 앱 사례

- **점신**: 앱인토스에 입점해 있다 ([토스피드](https://toss.im/tossfeed/article/41463)). 자체 앱 처리방침에서 생년월일시를 필수 수집한다 ([처리방침](https://www.jeomsin.co.kr/policy/)). 회원가입·서버 저장 구조라 이 앱과 전제가 다르다.
- **개인 개발자 사주·궁합 미니앱 후기 2건**: 검수 통과는 언급하지만 처리방침·동의 여부는 언급하지 않는다 ([후기1](https://www.gpters.org/uiux/post/toss-mini-app-launch-V009df8f2xHfUzx), [후기2](https://brunch.co.kr/@expnote/270)).
- 앱인토스 안 운세 미니앱들이 입력 시 고지·동의 화면을 띄우는지는 `확인 필요` (토스 앱에서 직접 2~3개 확인)

## 적용할 것

1. **입력 화면 안내 문구** (예시)
   > 입력한 생년월일과 태어난 시간은 이 기기에만 저장돼요. 서버로 보내지 않고, 만든 사람도 볼 수 없어요. 토스 앱을 지우거나 [내 정보 지우기]를 누르면 삭제돼요.
2. **내 정보 지우기** 기능 제공
3. **간단한 처리방침 페이지**: 처리 항목(생년월일, 태어난 시 선택), 목적(운세 계산), 처리 위치(기기 내부만), 삭제 방법, 익명 사용자 키·토스 통계 사용 사실, 문의 이메일. 미니앱 번들 안 정적 페이지로 넣는다.
4. **하지 않을 것**
   - 공유 링크·쿼리·이벤트 로그에 생년월일 넣기
   - 익명 사용자 키와 생년월일을 묶어 어디로든 보내기 (이 순간 처리방침 필수가 될 가능성이 큼)
   - 진입 직후 동의 바텀시트 띄우기 (출시 가이드 위반)
