# 앱인토스 출시 요건 조사

조사일: 2026-11-22 · 출처: 앱인토스 개발자센터(developers-apps-in-toss.toss.im) 공식 문서, 토스 공식 블로그
콘솔에는 로그인하지 않아 실제 등록 화면은 확인하지 못함.

## 결론

사업자등록 없이, 서버 없이, 비용 없이 출시할 수 있다. 공식 문서에 운세·사주를 막는 조항은 없다.
다만 **공유 방식**에 제약이 크다. 토스 앱이 없는 사람은 공유 링크를 웹에서 열 수 없고, 카드 이미지를 바로 보내는 공유 API가 없다.

## 프로젝트에 미치는 영향

1. **공유 방식 재설계 필요**: "카드 이미지를 친구에게 바로 전송"은 안 된다. 가능한 방식은 아래 두 가지다.
   - 공유 링크: 친구가 토스 앱에서 같은 카드(또는 자기 카드)를 연다. 토스 앱이 없으면 앱스토어로 간다.
   - 카드 이미지 저장: 사용자가 저장한 뒤 카카오톡·인스타 등으로 직접 보낸다.
   - 사용자마다 다른 미리보기 이미지는 외부 이미지 저장소가 필요해서 무료·서버 없음 원칙과 충돌한다.
2. **이용자 만 19세 이상**: 대상 사용자 범위가 좁아진다.
3. **3D 그래픽 성능 검증이 먼저**: iOS 메모리 제약으로 흰 화면 위험이 문서에 경고돼 있다. QR 테스트로 실제 기기 확인이 필요하다.
4. **라이트 모드만 지원**: 현재 카드 디자인(흰 카드)과는 맞다.
5. **운세 문장 생성에 AI를 쓰는 경우**: 미리 생성해 둔 문장이라도 생성형 AI 결과물로 보는지 `확인 필요`. 해당되면 고지·라벨이 의무다.
6. **사용자 데이터**: 생년월일은 기기 저장으로 유지하고, 공유 링크 쿼리에는 생년월일을 넣지 않는다 (문서 근거 아닌 설계 권고).

## 다음에 확인할 것

- 콘솔 가입 후 앱 등록 화면 확인: 개인정보 처리방침 입력란, 카테고리, 개인 워크스페이스
- 채널톡 문의: 운세 고지 필요 여부, 미리 생성한 AI 문장의 라벨 의무, 번들 내 OG 이미지 사용 가능 여부
- 샌드박스·QR 테스트로 three.js·셰이더 실기기 성능 측정
